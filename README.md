# OpenCrabs Showcase — Audio & Remotion Project

Soundtrack and sound effects for the OpenCrabs retro showcase video.

## Official Links

- **Website:** [opencrabs.com](https://opencrabs.com)
- **GitHub:** [github.com/adolfousier/opencrabs](https://github.com/adolfousier/opencrabs)

## Contents

| File | Description |
|------|-------------|
| `source-original.mp4` | Original showcase video (no enhanced audio) |
| `showcase-synthwave.mp4` | Enhanced with synthwave soundtrack + SFX |
| `soundtrack-synthwave.wav` | Synthwave soundtrack (120 BPM, Am-F-C-G) |
| `remotion-src/` | Remotion source code for the showcase video |

## Video Structure

10 slides × 6 seconds each, transitions at 5.5s intervals.

| Slide | Time | Content |
|-------|------|---------|
| Intro | 0–5.5s | OPENCRABS logo + fireworks |
| 01 | 5.5–11.5s | MULTI-CHANNEL |
| 02 | 11.5–17.5s | BROWSER |
| 03 | 17.5–23.5s | CODE & FILES |
| 04 | 23.5–29.5s | WEB RESEARCH |
| 05 | 29.5–35.5s | 24/7 AUTO |
| 06–09 | 35.5–53.5s | More features |
| Outro | 53.5–60s | Links + CTA |

## Audio Versions

- **v1 — Synthwave** (current): 120 BPM, sawtooth bass, detuned pads, square arp, SFX synced to transitions
- **v2 — Lo-fi** (WIP): Relaxed lo-fi beat, vinyl crackle, jazz chords, softer SFX

## Built with

- [Remotion](https://remotion.dev) — video rendering
- [OpenCrabs](https://github.com/adolfousier/opencrabs) — the AI agent that built this
